# Frontend

Aplicación React + Vite del portafolio. La API de contacto está en el repositorio
independiente [Nicoherr/portafolio-backend](https://github.com/Nicoherr/portafolio-backend).

Para desarrollo local, ejecuta la API en el puerto 3001; Vite reenvía `/api` a
ese servidor. Para producción, define `VITE_API_URL` con la URL pública de la
API antes de compilar. Consulta el [README del repositorio](../README.md) para
las instrucciones completas.

Comandos de desarrollo y compilación disponibles:

```sh
npm run dev
npm run build
npm run lint
npm test
```
